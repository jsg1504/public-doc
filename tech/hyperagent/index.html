HyperAgents: Metacognitive Self-Modification for Open-Ended Self-Improvement

DGM-Hyperagents(DGM-H) — 자기 개선 메커니즘 자체를 수정 가능하게 만들어, 코딩을 넘어 임의의 computable task에서 self-accelerating improvement를 달성하는 프레임워크.

01 Section

문제 정의 & 배경

Self-improving AI의 근본적 한계: 고정된 meta-level 메커니즘이 개선 속도를 제한한다.

Problem

DGM의 한계: 고정된 meta 메커니즘 & 도메인 의존성

Darwin Gödel Machine(DGM)은 코딩에서 open-ended self-improvement를 입증했지만, self-improvement instruction을 생성하는 meta-level 메커니즘이 handcrafted & fixed이다. 이 메커니즘은 수정 불가능하여 개선 속도를 병목시킨다.

Fixed instruction-generation: 메타 메커니즘이 수정 불가 → 개선 능력의 천장 존재
Alignment 가정: "평가 태스크 skill = self-modification skill" — 코딩 외 도메인에서는 성립하지 않음
Meta-meta 시스템 추가해도 근본 해결 안 됨 — 무한 regress 발생

03 Section

실험 결과

코딩, 논문 리뷰, 로보틱스 reward design, 올림피아드 수학 채점 — 4개 도메인에서의 self-improvement.

Metrics

Test-set 성능 (initial → DGM-H, 100 iterations)

0.71 Paper Review (test) 0.0 → 0.710 (CI: .59–.75) baseline static: 0.630 · DGM-custom: 0.590
0.37 Robotics Reward Design (test) 0.060 → 0.372 (CI: .36–.44) default reward: 0.348 · DGM-custom: 0.348
0.27 Polyglot Coding (full) 0.084 → 0.267 (CI: .23–.28) 원래 DGM: 0.142 → 0.307

모든 도메인에서 initial agent(거의 0점)에서 유의미한 성능 향상 달성. Coding에서는 coding-specific DGM과 동급, 나머지 도메인에서는 DGM-custom 능가 또는 동급 (p<0.05).

Ablation

핵심 컴포넌트가 모두 필요하다 (Paper Review · Robotics)

(CI: 0.36–0.44) → metacognition + open-ended 탐색 모두 있을 때만 지속적 개선

DGM-H는 두 baseline 대비 모든 도메인에서 p<0.05로 유의미하게 우수. metacognitive self-modification과 open-ended exploration 둘 다 필수.

04 Section

Transfer · Compounding · Safety

Meta-level 개선이 도메인 간 transfer되고, 실행 간 compound되며, 안전성 고려사항.

Transfer & Compounding

도메인 간 transfer & compound (Olympiad Math Grading)

0.00 DGM transfer imp@50 CI: 0.0–0.01 DGM-custom으로 학습한 meta agent → 새 도메인에서 개선 능력 없음
0.63 DGM-H transfer imp@50 CI: 0.54–0.63 hyperagent로 학습한 meta agent → unseen 도메인에서도 유의미한 개선 (p<0.05)
0.70 DGM-H + transfer (200 iter) vs ProofAutoGrader 0.670 transfer hyperagent에서 출발 → higher median & CI. full IMO-GradingBench: 0.561→0.601

DGM-H가 배운 self-improvement 전략(performance tracking, persistent memory 등)은 도메인 무관으로 transfer되고, 다른 도메인에서 계속 running하면 compound됨. 잠재적으로 unbounded open-ended self-improvement의 가능성 시사.
