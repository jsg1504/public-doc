새 문서 추가하기
01
FOLDER STRUCTURE

주제별 폴더를 생성하고 그 안에 index.html을 추가하세요.

예: travel/australia/index.html
→ URL: /travel/australia

02
UPDATE DOCS.JSON

루트의 docs.json에 문서 정보를 추가하면 이 페이지에 카드가 자동 생성됩니다.

필드: title description path category icon date

03
COMMIT & PUSH

변경사항을 커밋하고 main 브랜치에 푸시하면 GitHub Pages가 자동으로 배포됩니다.

git add .
git commit -m "docs: 새 문서"
git push
